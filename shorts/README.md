# Shorts & Reels (short-form first)

Owner decision 2026-11-27: start the channel with Shorts/Reels only. Long videos come later from `scripts/`.

- One folder per city: `shorts/<slug>/`
- One file per Short: hook, narration with fact IDs, clean ElevenLabs text, scene prompts for Google Flow, edit notes, publish pack (YouTube + Instagram).
- Facts come from `research/<slug>/sources.md` (shared with the long video).
- Voice: ElevenLabs v3, Viraj, old-radio filter (`config/channel.json`). Paste only the "ElevenLabs text" block (no [F#] tags).
- Format: 1080x1920, 30 fps, 30-55 s. Log music/visual sources in `shorts/<slug>/CREDITS.md`.
- Posting plan: `shorts/SCHEDULE.md`.
