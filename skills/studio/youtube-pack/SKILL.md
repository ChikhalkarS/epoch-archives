# YouTube pack → `episodes/<ep>/youtube.md`

- **Titles (3):** Hindi question or contrarian claim + English keyword, ≤ 60 chars, with a number or object where possible. Pattern: `भोपाल की झील किसने बनाई? | EP1 Hidden History of Bhopal`. Never reuse Quiet Wolf title phrases.
- **Description:** 3 short paragraphs that retell the story (belief → dated origin → one-line moral), then `Sources:` as `- Author/Org, "Title", Publisher, Year [F#]` for every fact ID used in the script, then hedges written out for disputed points, then chapters (from `renders/chapters.txt`), then credits (music, font), then 3–5 hashtags ending in `#इतिहास #history`.
- **Tags:** 15–20 (Hindi, English, Hinglish).
- **Shorts copy:** per Short: title (≤ 50 chars, number/object), 2-line description + 2–3 sources + "पूरी कहानी: <long URL>", and set the related video to the long EP.
- **Thumbnail:** one Flow/Whisk still prompt (style block) + 2–3 Hindi words + EP badge.
- Owner uploads. Never publish.
